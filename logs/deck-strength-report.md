# 牌组强度 × Act3 死因 诊断报告

- 模型：`checkpoints/v10_seg3.pt`（Scorer 477→369, hidden 512/256, greedy）
- 战斗：`LightspeedEnv(mcts_simulations=20000)`；种子 `make_eval_seeds(200)[:60]`
- 样本：60 局 → **A 通关 28 局** / **B 死 Act3 19 局** / 其他(死 Act2 等) 13 局（不计入对比）

## 1. 方法与口径

- **采集点**：每局在 `env.gc.act == 3` 的**首个宏观决策点**快照牌组（act 切换发生在上一幕 Boss 奖励后，故反映进 Act3 时的真实牌组）。
- **字段来源**（3 局试探确认 `gc.deck`/`gc.relics` 为对象，非 dict）：
  - 卡：`c.id.name` / `c.rarity.name` / `c.upgraded`(bool) / 费用回退 `card_data.get_base_cost(c.id.name)`
  - 遗物：`len(gc.relics)`；药水：`gc.potion_count`；血：`gc.cur_hp` / `gc.max_hp`
- **探针示例**（seed 856258841 进 Act3）：30 张 / 稀有 4（DEMON_FORM,FIEND_FIRE,CORRUPTION,FIEND_FIRE） / 升级 2（POMMEL_STRIKE×2）/ 遗物 10 / 药水 1 / HP 80-80。字段均可正确读取。
- **显著性**：Welch t 检验（手动 betai，无 scipy），双侧 p<0.05 记显著；并给 Cohen's d 效应量。

## 3. 结论

- **假说成立 ✅（但定位到具体维度）**：通关局进 Act3 时的牌组**显著强于** Act3 死亡局，但差距不在「牌组规模/稀有卡」——而在**升级卡数(+2.44, p=0.030, d=0.59)** 与 **遗物数(+1.24, p=0.038, d=0.65)**。稀有卡数(3.14 vs 3.16, p=0.967)、牌组张数、平均费用、药水数两组均无显著差异。
- **瓶颈在宏观决策质量（选牌/路线/商店/篝火的长期收益），不是战斗执行层**：两队进 Act3 时血线(max_HP 80.2 vs 70.2, p=0.068 仅边际)与药水相当，死亡局并非被血线拖垮，而是带着「升级更少、遗物更少」的牌组进 Act3——与已排除的「满血进 Boss 仍死」一致：问题出在战斗前的牌组积累，而非战斗中。
- **差距最大的两个可行动指标**：① **升级卡数**（绝对差 +2.44 张，死亡局仅约 60% 的通关局升级量——最大绝对缺口，纯篝火/升级决策杠杆）；② **遗物数**（效应量最大 d=0.65）。后续训练应优先奖励「长期升级收益」与「遗物获取」（篝火升级、商店/事件遗物与卡牌升级路线），而非单纯追稀有卡或堆牌数。
