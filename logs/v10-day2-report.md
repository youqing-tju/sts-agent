## 二、三条核心结论

### 1. 数据分布匹配 ≫ 数据来源权威性 ⭐
同样是**行为克隆**，只换数据来源：

| BC 数据 | 楼层 | 通关率 |
|---|---|---|
| A20 人类 `.run`（"高手数据"） | 27.53 | 6.7% |
| **A0 自对弈**（自己打的数据） | **45.40** | **50.0%** |

**差 18 层 / 43 个百分点。** 昨天的结论"BC 预热是负迁移"**已更正**为：
> **不是 BC 有问题，是数据分布不匹配。** 场景不同（A20 vs A0）时，再"权威"的人类数据也是负迁移；
> 而我们用模拟器可以**廉价地生成精确匹配场景的数据**。

### 2. BC 自对弈 = "能力复制"的极高效路径
E1 单独用 RL 训练 **8000 局**才到 46.30 层；而**采样 300 局 + BC 训练几分钟**（0 局 RL）就到 **45.40 层**。
→ 一旦有了强模型，"采样 → BC" 能把它的能力快速复制给新网络（效率约 26×），
适用于**换新表征后快速热启动**。

### 3. 训练是"非单调"的 —— 峰值常出现在中前期
两次独立证据：
- 分段训练：42.8 → **48.4** → 44.1
- 自对弈微调：45.5 → **48.9（@432 局）** → 46.0

→ **不能"用最后一个 checkpoint"**。必须保存多个候选并各自评估、择优。

## 三、当前最优配方（可复现）

```
1) 从零训练约 8000 局                                →  E1（46.30 / 56.7%）
2) 分段续训（每段 3000 局，各自独立 checkpoint）
   + 每段结束时用固定种子评估 → 择优   →  段3（48.43 / 70.0%）🏆
3) 可选：自对弈采样 → BC 预热（快速复制 / 新表征热启动）
```
